# UcxStats 0.12.3.5 Beta

This Beta follows public 0.12.3.4. Numeric application, assembly, product and
installer versions are **0.12.3.5**, defined once in `Directory.Build.props`.
Beta is the pre-release distribution label. The user will create the Git tag and
GitHub pre-release manually after the source push and Windows packaging checks.

## New functionality

- Optional map statistics use the exact all/source/selected/SQL/Live QSO scope:
  total, mappable and non-mappable counts; distinct DXCCs and valid Maidenhead
  fields/grids; exact multi-band unions; per-band summaries and profile-aware ODX.
- Optional contest-time analysis estimates counted time and pauses from UTC QSO
  timestamps. The pause threshold is configurable (60 minutes by default); a gap
  strictly greater than it counts entirely as a pause. Optional allowance tracking
  and full-scope time analysis are independent of visible bands.
- Live QSO histogram: rolling 15–240-minute window, exact 1/2/5/10-minute UTC
  buckets, proportional bars, restrained gap coloring, latest-QSO details and a
  one-second timer that runs without file changes or SQLite polling.
- Independently draggable/collapsible map panels with saved normalized positions,
  offscreen recovery and reset. Resize the timeline to 20–320 px: miniature
  20–39, compact 40–99, full 100–320. Keyboard resize and F2 settings access remain
  available; one timeline visibility control and no redundant inline button.
- Warning/prolonged sliders have fixed 1–179 / 2–180-minute limits, safe pointer
  capture/clamping and strict ordering. The range-growth overflow is corrected;
  existing wider configurations are retained until an explicit slider edit.
- General preferences persist atomically in `%LOCALAPPDATA%\UcxStats\map-settings.json`.
  Widths, panel settings and timeline choices are preserved; DXCC options remain
  separate in `map-dxcc.json`. Upgrades preserve databases, sources and external paths.

## UCX source reconciliation correction

Manual and Live imports now reconcile complete source snapshots in one SQLite
transaction: insert new records, update changes, preserve unchanged hashes and
delete absent path/index identities. A valid stable empty source removes its QSOs
while retaining source configuration. Read/parse/validation/SQL failures roll back;
other sources, profiles and unrelated DCL evidence remain intact.

Stable reads and final validation reject changing/stale snapshots; destructive
Windows commits require a read-only file lease. Geo caches cascade/rebuild in the
transaction, and deleted database IDs are not reused. If a record's DCL matching
fields change, only that row's stale match is cleared; reimport DCL to rematch it.
Live refresh removes deleted geometry and updates statistics/latest activity and
histogram counts without reloading HTML or resetting map presentation state.
Real-file integration tests cover `2 → 1 → 0`, failure/rollback, source isolation,
repeated events and overlapping imports through the generated map contracts.

## Known limitations and Windows follow-up

- QSO gaps do not establish actual operator inactivity or operating pauses.
- Contest operating time is a QSO-derived estimate, not guaranteed ruleset compliance.
- No CAT-based active-band detection; the displayed band belongs to the last QSO.
- External DXCC GeoJSON is not bundled and must be supplied separately.
- The installer is unsigned and may trigger Windows SmartScreen warnings.
- UCX has no commit marker: a closed writer leaving a valid stable shorter/empty
  file is indistinguishable from an intentional edit. Native Windows sharing,
  watcher/source-switching and final installer checks remain pending.

Earlier map/timeline UI Windows acceptance is user-reported. Linux checks do not
execute WPF, WebView2 or Inno Setup. Run the [source deletion checks](../MAP_STATISTICS.md#ucx-deletion-reconciliation-and-live-refresh)
and [Windows installer checklist](../WINDOWS_INSTALLER.md#windows-release-smoke-test-checklist).

## Transfer and installer

The standalone transfer archive is `artifacts/UcxStats-Packaging-0.12.3.5-win-x64.zip`
with a `.sha256` sidecar; staging is `artifacts/packaging/win-x64/0.12.3.5/`.
It includes the complete self-contained Windows payload, WebView2 loader, local
Leaflet assets, MIT/third-party notices and standalone packaging scripts; user data,
credentials, local settings and external geometry are excluded.

On Windows, extract into a new writable directory, install Inno Setup **6.7.3**,
then run the extracted `package.ps1` as described in the [installer guide](../WINDOWS_INSTALLER.md#01235-beta-transfer-package).
The result is `output/UcxStats-Setup-0.12.3.5-win-x64.exe`. A Git checkout, .NET SDK
or repository-relative files are not needed on Windows.
